# 作品集演示政策 / Portfolio demonstration policies

均为本作品集项目的演示政策，已由用户逐条确认；它们不代表真实酒店的服务承诺。
确认依据见 [Feature 04 需求澄清与演示政策](../../17-the-wild-oasis-ai/docs/design/2026-08-29-policy-rag/DRAFT.md)。

实时住宿限制、人数限制和早餐价格继续以应用的结构化 settings 工具为准。
订单备注、测试数据和模型常识不属于政策来源。

本说明覆盖整个 public/staff 政策集合，放在导入目录 `policies/` 之外，
不参与政策分块、Embedding、版本 Hash 或检索引用。
